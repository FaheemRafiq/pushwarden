The threat

It gets in through a project you trust

PolinRider is a campaign attributed to North Korean (DPRK, Lazarus) operators. It targets software developers, often through fake job interviews in which the victim is asked to clone and run a repository.

  1. It hides in ordinary project files

    Obfuscated loaders are appended to config files such as postcss.config.mjs, placed in files that pretend to be fonts, and started by .vscode/tasks.json tasks that run when a folder is opened.

  2. It runs when you open or build the project

    Opening the folder in the editor or starting the dev server is enough. Tokens, SSH keys, browser sessions and wallet files are collected and sent to command servers.

  3. It spreads through git

    With a stolen token it rewrites repositories and force-pushes the backdoor to every branch it can reach, so colleagues who pull become infected too.

Protection

Install it once. It has your back.

PushWarden runs quietly in the background and watches your projects for you. Anything it removes you can put back, and it always tells you why it acted.

Always watching

A new file in your projects is checked within a second of being written. Running programs and network connections are checked every five seconds.

Real-time guard

Nothing is lost

A bad file is locked away before it can run, and you are shown what was found. Changed your mind? Put it back with one command.

Response and recovery

The attackers are cut off

Your computer is stopped from talking to the malware's servers, so nothing can be sent to them. The block stays after a restart.

Blocking C2 servers

Safe to open a project

VS Code and editors like it are set so that opening a folder cannot run anything on its own.

Install

Get PushWarden

One step, and only for your own user account. Coming from ThreatScan, the earlier name of this program? See moving to PushWarden.

Windows 10 and 11 your system

PushWarden-Setup.exe

The installer is not code-signed yet. If SmartScreen appears, choose More info, then Run anyway.

Afterwards, open PushWarden from the Start menu to check and clean your GitHub repositories on guided screens.

macOS 11 or later your system

Intel and Apple silicon. Open Terminal (Applications, Utilities, Terminal), paste this and press Return. No password needed:

curl -fsSL https://raw.githubusercontent.com/FaheemRafiq/pushwarden/main/installers/install.sh | sh

It downloads PushWarden, checks its SHA-256 against the published list, and sets it up for your user.

Prefer an installer? PushWarden.pkg

The package is not notarized yet, so macOS blocks it the first time ("unidentified developer"). Try to open it once, then go to System Settings, Privacy & Security, and click Open Anyway (it appears for about an hour). Or install it from Terminal: installer -pkg ~/Downloads/PushWarden.pkg -target CurrentUserHomeDirectory

Afterwards, open PushWarden from the Applications folder in your home folder to check and clean your GitHub repositories on guided screens.

Linux your system

Run in a terminal (no sudo):

curl -fsSL https://raw.githubusercontent.com/FaheemRafiq/pushwarden/main/installers/install.sh | sh

Or install a package (with sudo; it sets PushWarden up for your user):

  • x86-64: .deb · .rpm
  • ARM64: .deb · .rpm

Afterwards, pushwarden ui checks and cleans your GitHub repositories on guided screens.

After installing, check it any time with pushwarden status. Every download is listed with its SHA-256 in checksums.txt, which is signed.
